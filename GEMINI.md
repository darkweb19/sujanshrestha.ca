# Gemini CLI entrypoint

Read `AGENTS.md`, `docs/portfolio-redesign-brief.md`, and relevant `.agents/skills/<slug>/SKILL.md` files. That directory is the sole authoritative source of skills. Optional local discovery alias: `node scripts/link-agent-skills.mjs`. Follow the actual Gemini host's available delegation and tool permissions; role names Luna and Terra are conceptual, not built-in agent identities.
