# Brand asset staging

These starter SVG paths were programmatically vectorized from the **third uploaded transparent, black S-monogram asset** supplied for the redesign. The horizontal wordmark combines that monogram with spacious text approximating the second uploaded horizontal version. Both are transparent and monochrome; they are not guaranteed pixel-perfect matches to the raster originals.

The implementation agent should visually compare these files with the user-provided source artwork, refine Bézier curves/letterforms or replace with optimized original exports when those files are available, and generate correctly sized `favicon.ico`, 32px/16px icon, `apple-icon` and OG assets. Do not ship an unverified square logo plus text as the 16px favicon. The existing site identity remains intact until the redesigned routes are implemented.
